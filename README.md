# Kocsmagaléria

Élőkép-játék a szakkolis kocsmatúrára. A játékosok becenévvel és csapatválasztással lépnek be, megkapják a csapatuk titkos festményleírását, beállnak, egy csapattag feltölti a fotót, a többiek pedig a telefonjukon tippelnek, melyik festmény volt az eredeti.

- Játékosoknak: https://barcazsolo.github.io/kocsmagaleria/
- Szervezőknek: https://barcazsolo.github.io/kocsmagaleria/#szervezo

A festmények közkincsek (a szerzők több mint 70 éve haltak meg).
